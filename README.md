# CURSO-UNITY

This project is related to a course designed to teach people how to create simple games using Unity. 

## About This Course

This repository contains sources and examples for learning Unity game development from the ground up. Whether you're a complete beginner or looking to improve your Unity skills, this course will guide you through the fundamentals of creating games with Unity.

## What You'll Learn

- Unity basics and interface navigation
- Game object creation and manipulation
- Scripting with C# for game logic
- Scene management and game flow
- Simple game mechanics implementation
- Building and deploying your games

## Getting Started

1. Clone this repository
2. Open Unity Hub
3. Add the project to Unity Hub
4. Open the project with a compatible Unity version
5. Follow along with the course materials

Happy game developing! 🎮
